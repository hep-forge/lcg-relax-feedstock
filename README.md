Feedstock for [lcg-relax](https://lcginfo.cern.ch/pkg/RELAX/) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

ROOT dictionaries for CLHEP, HepMC, ROOT Math and STL containers

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/lcg-relax](https://anaconda.org/hep-forge/lcg-relax).


## Install

```bash
conda install -c hep-forge -c conda-forge lcg-relax
```
